# 🌐 Frameworks – 2º DAM

Repositorio de prácticas, ejercicios y proyectos desarrollados en la asignatura **Frameworks**.  
Una materia **fundamental** para comprender y aplicar las **tecnologías web modernas**, utilizando **frameworks de frontend y backend** que permiten crear aplicaciones dinámicas, escalables y profesionales.

---

## 🎯 Objetivos de la asignatura

- Comprender el papel de los **frameworks** en el desarrollo de aplicaciones web modernas.  
- Utilizar **Bootstrap** para diseñar **interfaces responsivas** y atractivas.  
- Desarrollar **aplicaciones web completas** con **Laravel** (backend PHP) y **Angular** (frontend TypeScript).  
- Aprender a conectar el frontend con el backend mediante **APIs REST**.  
- Aplicar principios de **arquitectura MVC**, **seguridad**, y **buenas prácticas de desarrollo**.  

---

## 🧩 Contenidos principales

1. **Introducción a los frameworks**
   - Qué es un framework y por qué se utiliza.  
   - Tipos de frameworks: frontend, backend y fullstack.  
   - Estructura, componentes y ciclo de vida de una aplicación web moderna.

2. **Diseño frontend con Bootstrap**
   - Sistema de rejilla y diseño responsivo.  
   - Componentes, utilidades y personalización.  
   - Integración con HTML, CSS y JavaScript.

3. **Desarrollo backend con Laravel**
   - Estructura MVC en Laravel.  
   - Rutas, controladores y vistas Blade.  
   - Conexión a bases de datos con **Eloquent ORM**.  
   - Autenticación, validaciones y middleware.  
   - Creación y consumo de **APIs RESTful**.

4. **Desarrollo frontend con Angular**
   - Estructura de un proyecto Angular (CLI).  
   - Componentes, directivas y servicios.  
   - Enlace de datos (data binding) y gestión de eventos.  
   - Consumo de APIs con **HttpClient**.  
   - Navegación, routing y modularización.

5. **Integración completa**
   - Conexión entre Angular (frontend) y Laravel (backend).  
   - Intercambio de datos mediante JSON y APIs REST.  
   - Despliegue de aplicaciones fullstack.  
   - Buenas prácticas, seguridad y documentación.
